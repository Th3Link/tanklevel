# TL-136 Liquid Level Sensor

This project provides a solution for **measuring the liquid level in tanks**, such as rainwater tanks, using the **TL-136 pressure sensor**. It is designed for **easy integration with home automation systems**, connecting via **Wi-Fi** or **Ethernet**.

## Features

- Measures liquid levels in tanks accurately using the TL-136 sensor.  
- Connectivity: Wi-Fi or Ethernet for integration with smart home systems.  
- Compact design to fit in a **3-way IP68 junction box** (minimum inner dimensions: 90 × 110 mm).  
- PCB target size: 80 × 60 mm.  
- Powered by a **24V supply**, e.g., MEAN WELL APV-8-24 (8W).
